# Programa InfraRodoviária — atalho para celular

Atalho instalável (PWA) que abre o painel do Programa InfraRodoviária Ceará em tela cheia, com o ícone 🛣️.

Este repositório tem só o atalho: ícones, manifesto e uma página que abre o painel publicado no Google Apps Script. O código do painel e os dados ficam em outro lugar; o acesso continua protegido pelo login do painel.

## Instalar

- **Android (Chrome):** abra o endereço do atalho → menu ⋮ → **Instalar app** (ou **Adicionar à tela inicial**).
- **iPhone (Safari):** abra o endereço do atalho → botão **Compartilhar** → **Adicionar à Tela de Início**.
